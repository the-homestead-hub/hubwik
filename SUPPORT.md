# Support

HubWīk is a public knowledge book with a small maintainer set. There is no
service-level agreement.

| Need | Where |
|---|---|
| Crop fact looks wrong | [Crop correction](https://github.com/the-homestead-hub/hubwik/issues/new?template=crop-correction.yml) |
| You have a source or observation | [Evidence](https://github.com/the-homestead-hub/hubwik/issues/new?template=evidence.yml) |
| Compiler or generated page is wrong | [Renderer bug](https://github.com/the-homestead-hub/hubwik/issues/new?template=renderer-bug.yml) |
| A larger change | [Proposal](https://github.com/the-homestead-hub/hubwik/issues/new?template=proposal.yml) |
| Vulnerability | [SECURITY.md](SECURITY.md) |
| Shop order, delivery, or till | The shop that sold you the kit — not this repository |

Editorial questions: [docs/EDITORIAL.md](docs/EDITORIAL.md).
Licence questions: [LICENSING.md](LICENSING.md).

Contact for the project: hello@thehomesteadhub.co.uk.
