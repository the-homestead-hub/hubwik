## Stile

<p>A stile is a step over a fence, not the field. The titled room is a threshold in this book: some knowledge will sit behind payment. It is not a second brand, not a declined name for Hubwik, and not a Keep in a three-door portal. Same contents list, last part.</p>

## x402

<p>x402 is an open protocol that uses HTTP 402 Payment Required. A client asks for a resource. The server answers 402 with payment requirements. The client pays and retries. Coinbase's documentation is the working description; this page does not re-specify the protocol. Liquid on Shopify cannot emit a 402. The Worker that does lives at <a href="https://stile.thehomesteadhub.co.uk/">stile.thehomesteadhub.co.uk</a> — a stile hostname, not the shop apex, so checkout is not put through the proxy.</p>
