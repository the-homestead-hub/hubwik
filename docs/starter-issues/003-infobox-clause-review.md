# Read the 18 flavour clauses against the live infobox

v0.1 refuses a flavour that ends in a clipped token. A good first pass is to
read each generated grow page infobox Flavour, Sow, and First cut against
`data/crops/*.md` and file a crop-correction issue for any clause that is
complete in the file but still reads unfinished.

Do not “fix” this by shortening flavour so it fits a shop theme. The compiler
must not truncate.
