# Record a measured dill yield

Dill is in the knowledge catalogue and is `incomplete`. The growing instruction
is present. `yield_min_g` / `yield_max_g` are not.

This issue is only for a measured or clearly sourced yield on a named variety,
with sow date, medium, and as-of date. Do not invent a number to close the
field. Do not add a nineteenth variety.

See `docs/OBSERVATION.md` and `docs/SAFETY.md`.
