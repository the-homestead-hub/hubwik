## Images

None in v0.1. To add an image, append a row with all of:

- file path
- author
- source URL or “original photograph”
- exact licence (must be compatible with how the file will be shipped)
- required attribution text
- modification status (original / cropped / redrawn)

Until that row exists, do not add the file.

## How to add a row

Open an evidence issue or a pull request that updates this table in the same
change that adds the material. Unregistered third-party prose will be refused.
